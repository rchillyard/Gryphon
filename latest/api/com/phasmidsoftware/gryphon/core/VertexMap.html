VertexMap

com.phasmidsoftware.gryphon.core.VertexMap
See theVertexMap companion object
case class VertexMap[V](map: Map[V, Vertex[V]]) extends Traversable[V]

Represents a mapping of vertex attributes to their corresponding vertices within a graph. Provides functionality to manage and traverse vertices via DFS and BFS using the Visitor V1.2.0 typeclass engine.

The mutable discovered flag pattern has been removed; visited-node tracking is now handled entirely by the immutable VisitedSet[V] inside the traversal engine.

Type parameters

V

the type representing the vertex attributes (invariant).

Value parameters

map

a mapping from vertex attributes to their associated Vertex instances.
