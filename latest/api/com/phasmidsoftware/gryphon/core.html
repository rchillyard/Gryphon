trait Connected[V]

Trait to model the capability of answering connectivity queries over a set of objects.

Trait to model the capability of answering connectivity queries over a set of objects.

A type implementing Connected[V] can determine whether any two objects of type V belong to the same connected component.

Note the distinction from Connexion[V], which models a specific edge between exactly two vertices. Connected[V] is a higher-level oracle over the whole structure.

Typical implementations: ConnectivityLazy, WeightedUnionFind, ConnectedComponents.
