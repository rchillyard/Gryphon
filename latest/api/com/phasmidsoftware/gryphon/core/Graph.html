Graph

com.phasmidsoftware.gryphon.core.Graph
See theGraph companion object
trait Graph[V] extends Traversable[V]

A trait representing an abstract graph structure composed of vertices.

All traversal methods delegate to the VertexMap which in turn uses the Visitor V1.2.0 typeclass engine (Traversal.dfs / Traversal.bfs). The mutable discovered flag pattern has been removed throughout; visited-node tracking is handled by the immutable VisitedSet[V] inside the engine.

Type parameters

V

the type representing the vertex attributes (invariant).
