com.phasmidsoftware.gryphon.traverse.VertexTraversalResult

case class VertexTraversalResult[V, T](map: Map[V, T]) extends AbstractVertexTraversalResult[V, T]

A concrete implementation of the TraversalResult trait that uses a map to represent vertex traversals. Each vertex in the graph is associated with a traversal result.

CONSIDER this class and its companion object are only used for unit testing. They could be eliminated.

Type parameters

T

The resulting type after traversing a vertex or an edge.

V

The type representing a vertex in the graph.

Value parameters

map

A map where each key is a vertex of type V, and the value is the corresponding traversal result of type T.

Attributes

Constructor

Creates a VertexTraversalResult with the given map of vertices and their associated traversal outputs.
