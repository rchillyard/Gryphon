def assert[T](b: Boolean)(msg: String)(t: T): Try[T]

Asserts a condition and returns a success or failure based on the outcome. If the condition is true, the method returns a success containing the value t. Otherwise, it returns a failure with an AssertionError containing the provided message.

Asserts a condition and returns a success or failure based on the outcome. If the condition is true, the method returns a success containing the value t. Otherwise, it returns a failure with an AssertionError containing the provided message.

Type parameters

T

the type of the value contained in the Try.

Value parameters

b

the condition to be asserted, which determines success or failure.

msg

the error message to include in the AssertionError if the condition is false.

t

the value to be returned in the Success case if the condition is true.

Attributes

Returns

a Try[T] containing the value t as a Success if the condition is true, or a Failure with an AssertionError if the condition is false.
