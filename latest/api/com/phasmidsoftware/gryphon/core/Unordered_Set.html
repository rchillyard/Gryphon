Unordered_Set

com.phasmidsoftware.gryphon.core.Unordered_Set
See theUnordered_Set companion object
case class Unordered_Set[T](elements: Set[T]) extends AbstractUnordered[T]

A case class representing an unordered collection of elements in the form of a Set.

Type parameters

T

the type of the elements contained in the set.

Value parameters

elements

a set of elements of type T forming the basis of the adjacency set. This class extends the Unordered trait, providing a concrete implementation for unordered data structures. The Unordered_Set is immutable, meaning that any operation resulting in modification (such as adding a new element) will return a new instance of Unordered_Set without changing the original instance.
